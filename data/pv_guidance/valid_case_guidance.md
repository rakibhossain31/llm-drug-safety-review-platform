# Synthetic PV Guidance: Minimum Valid Case

This document is educational and does not replace organizational procedures or regulatory requirements.

## Four minimum elements
A report is treated as a minimum valid individual case safety report when all four elements are present: an identifiable patient, an identifiable reporter, a suspect medicinal product, and an adverse event or reaction. Identifiability can be supported by reasonable information such as age, sex, initials, patient identifier, reporter role, or reporter contact information.

## Review action
When an element is missing, keep the report in a pending review state and request targeted follow-up. Do not infer a missing element merely to make the report valid. A human reviewer must confirm validity.
